# Results Directory

This directory contains selected benchmark evidence, raw CSV files, and summary indexes for the LLM-assisted Isabelle/HOL prover experiments.

## Layout

```text
benchmark_evidence/   Selected CSV files for headline comparisons
raw/                  Raw prover and planner runs
summaries/            Machine-readable indexes of included results
```

Start with `summaries/benchmark_evidence_index.csv` to identify which raw files support each comparison.
